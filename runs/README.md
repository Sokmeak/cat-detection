# Training Runs Directory

This directory will contain all training runs and results generated by YOLOv8.

## Structure

After training, this directory will contain:

```
runs/
└── train/
    ├── cat_detection_original/      # Training on original dataset
    │   ├── weights/
    │   │   ├── best.pt             # Best model weights
    │   │   └── last.pt             # Last checkpoint
    │   ├── results.png             # Training curves
    │   ├── confusion_matrix.png    # Confusion matrix
    │   ├── F1_curve.png           # F1 score curve
    │   ├── PR_curve.png           # Precision-Recall curve
    │   ├── P_curve.png            # Precision curve
    │   ├── R_curve.png            # Recall curve
    │   ├── results.csv            # Metrics in CSV format
    │   └── args.yaml              # Training arguments
    │
    └── cat_detection_enhanced/      # Training on enhanced dataset
        ├── weights/
        │   ├── best.pt
        │   └── last.pt
        ├── results.png
        ├── confusion_matrix.png
        └── ... (same structure as above)
```

## Auto-Generated

These directories are automatically created by YOLOv8 during training. You don't need to create them manually.

## Results Location

After running:

```bash
python training/train_yolo.py --name cat_detection_original
```

Results will be saved to: `runs/train/cat_detection_original/`

## Comparing Results

To compare original vs enhanced dataset results, check:

- `runs/train/cat_detection_original/results.png`
- `runs/train/cat_detection_enhanced/results.png`
